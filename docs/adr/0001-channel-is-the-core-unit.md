# The channel is the core unit, with memberships from day one

Every analytics record belongs to exactly one channel, and a user reaches a channel only through a membership. Version 1 serves creators with one channel each, so a user-owns-channel model would be simpler today, but the agency workspace needs many memberships per user, and moving from a user-centred model to a channel-centred one later touches every table. A creator is one membership; an agency is many.
