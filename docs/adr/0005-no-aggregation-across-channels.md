# No aggregation across channels; agencies get an export workbook

YouTube Developer Policies III.E.2.a forbid aggregating API data except across channels under one content owner recognised by YouTube, which a normal agency is not. The agency workspace therefore switches between channels and shows no totals. Agencies that want to report on their combined numbers get an export workbook with one tab per channel and combine it themselves, outside the product. An export API is ruled out by III.I.15.

Proposed until Google confirms, through the compliance audit form, that a single workbook with per-channel tabs is not aggregation. The fallback is one file per channel.
